# Changelog

Notable user-visible changes are documented here. Release files and checksums
are published on the [GitHub Releases](https://github.com/puritsonjit/soundboard-studio/releases)
page.

## Unreleased

- Accepted into the SignPath Foundation open-source signing program.
- Refreshed public documentation and release verification guidance.

## [1.0.0] - 2026-07-22

### Added

- 24 configurable sound pads with single-sound and random sound-pack modes.
- Per-pad labels, artwork, colors, volume, and global keyboard shortcuts.
- A clip editor that trims imported audio to the permanent 15-second limit.
- Local and temporary private Internet phone remotes with QR connection.
- Stack, Solo, and Stop All playback controls.
- 48 kHz microphone and soundboard mixing through VB-CABLE.
- Soundboard-only local monitoring and local-only desktop previews.
- ZIP profile import and export with managed sound and image copies.
- Automatic VB-CABLE setup assistance and verified helper downloads.
- One-file, console-free Windows packaging with a borderless loading screen.

### Release Status

The v1.0.0 preview assets are unsigned. Their release page provides SHA-256
checksums and links to the verified GitHub Actions build. A signed artifact will
be published separately after the approved SignPath integration is complete.
