# Uninstalling Soundboard Studio

Soundboard Studio is portable and does not register itself as an installed
Windows application.

1. Stop the phone remote and close Soundboard Studio.
2. Delete `SoundboardQt6.exe` and the `data`, `runtime`, `driver`, `licenses`,
   and documentation files beside it.
3. If VB-CABLE is no longer needed by any application, uninstall it from
   Windows Settings under Apps, then restart Windows if requested.

Deleting `data` and `runtime` permanently removes profiles and managed copies
of pad sounds and images. Export a profile ZIP first if it should be retained.
